# javascript-learning-lab

Repositorio personal de práctica y aprendizaje de JavaScript.

## Objetivos
- Comprender los fundamentos de JavaScript.
- Resolver problemas mediante ejercicios prácticos.
- Aprender a depurar errores y escribir código claro.
- Desarrollar pequeños proyectos de manera independiente.
- Registrar mi progreso durante la formación técnica.

## Método de aprendizaje
1. Estudiar un concepto.
2. Intentar aplicarlo sin copiar soluciones.
3. Probar el código y corregir errores.
4. Explicar lo aprendido con mis propias palabras.
5. Registrar las dudas y los avances.

## Progreso
- [ ] Variables: `let` y `const`
- [ ] Tipos de datos y operadores
- [ ] Condicionales
- [ ] Bucles
- [ ] Funciones
- [ ] Arrays y objetos
- [ ] Manipulación del DOM

Este repositorio es exclusivamente educativo e independiente de los proyectos de clientes.
